# Overlay is click-through except during display-region adjust

The overlay sits on the game. Always-draggable subtitles steal clicks meant for in-game controls. Display-region adjust is armed from settings for one target at a time: a region pair (that pair's display region takes the mouse, both rectangles outlined), or the optional dark-screen display, or the optional dialogue-option display. Extra-path adjust only arms when that display already exists; the first rectangle is boxed, and while armed only that display is outlined (there is no capture region). Otherwise the overlay — subtitles, hints, and the region-pair preview — is click-through.
